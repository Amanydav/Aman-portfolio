# 🌟 Personal Portfolio Website

Welcome to the my personal portfolio! This project showcases my skills, experience, and projects in an interactive and visually appealing way. Built with modern web technologies, it serves as a dynamic representation of my work as a web developer.  

## 🚀 Live Demo  
👉 [Explore My Portfolio Here](https://aman-portfolio-04.netlify.app)  

## 🛠️ Features  
- **Responsive Design**: Fully optimized for both desktop and mobile devices.  
- **Interactive UI**: Built using React and styled with Material-UI/Bootstrap for a smooth user experience.  
- **Storybook Integration**: Component-driven development with an interactive component library.  
- **Dynamic Components**: Includes typewriter effects, carousels, and other modern UI elements.  
- **Projects Section**: Highlights some of my key projects with live demos and code repositories.  

## ⚙️ Tech Stack  
- **Frontend**: React, TypeScript  
- **Styling**: Bootstrap, Reactstrap  
- **Component Library**: Storybook  
- **Other Tools**: EmailJS, Typewriter Effect, Webpack  

## 🛠️ Setup Instructions  
Follow these steps to run the portfolio locally:  

1. Clone the repository:  
   ```bash  
   git clone https://github.com/Amanydav/Aman-portfolio.git  
   cd portfolio 
   ```  

2. Install dependencies:  
   ```bash  
   cd frontend  
   npm install  
   ```  

3. Start the application:  
   ```bash  
   npm run start  
   ```  

4. Launch the Storybook library:  
   ```bash  
   npm run storybook  
   ```
